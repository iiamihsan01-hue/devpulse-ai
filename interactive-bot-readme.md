# Interactive Bot - Ellie

An adorable, interactive elephant bot widget that you can embed on any webpage.

## Overview

Ellie is a cute interactive bot character designed as an embeddable widget. Users can interact with the animated elephant character to create engaging experiences on your website.

## Live Demo

[View Interactive Bot](https://iiamihsan01-hue.github.io/interactive-bot/)

## Tech Stack

- **HTML5** — semantic markup
- **CSS3** — animations and styling
- **JavaScript** — interactivity and event handling
- **TypeScript** — type-safe scripting (optional)

## Features

✨ **Adorable Character** - Cute, engaging elephant bot design  
🎯 **Interactive** - Responds to user interactions  
🎨 **Animated** - Smooth, fluid animations  
📱 **Responsive** - Works on all screen sizes  
🔗 **Embeddable** - Easy to embed on any website  

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/iiamihsan01-hue/interactive-bot.git
   cd interactive-bot
   ```

2. Open `index.html` in your browser

## Embedding Ellie on Your Website

To embed the bot on your site, include the bot script in your HTML:

```html
<script src="bot.js"></script>
<div id="bot-container"></div>
```

Then initialize with:

```javascript
initializeBot();
```

## Customization

You can customize Ellie's appearance and behavior:
- Edit `bot.css` for styling changes
- Modify `bot.js` to change interactions
- Adjust animations in the CSS file
