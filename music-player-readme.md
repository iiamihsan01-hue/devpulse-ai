# Music Player

A web-based music player built with HTML, CSS, and JavaScript.

## Overview

A clean, functional music player application for playing audio files directly in your browser. Features an intuitive interface with standard playback controls.

## Tech Stack

- **HTML5** — audio element and semantic markup
- **CSS3** — modern styling and animations
- **JavaScript** — player controls and event handling

## Features

🎵 **Play/Pause Control** - Start and stop playback  
⏭️ **Track Navigation** - Skip forward and backward  
🔊 **Volume Control** - Adjust playback volume  
⏱️ **Time Display** - Current time and total duration  
📊 **Progress Bar** - Visual track progress indicator  
📝 **Playlist Support** - Play multiple songs  

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/iiamihsan01-hue/music-player.git
   cd music-player
   ```

2. Open `music-player.html` in your browser

## Usage

1. **Add Music Files** - Place audio files in the project directory or link to online sources
2. **Update Playlist** - Edit the JavaScript to add your audio file paths
3. **Play Music** - Use the player controls to play, pause, and navigate tracks

## Customization

Customize the player by editing:
- **Styling** - Modify CSS in `music-player.html` for colors and layout
- **Controls** - Adjust JavaScript functionality for custom behaviors
- **Playlist** - Update the audio file array in the JavaScript section

## Browser Support

Works on all modern browsers that support HTML5 Audio element:
- Chrome/Edge
- Firefox
- Safari
