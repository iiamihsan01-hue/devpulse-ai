# CafeTaccino

A stylish cafe/coffee shop website with modern design and interactive elements.

## Overview

CafeTaccino is a responsive web application showcasing a cafe/coffee shop with an elegant design, menu display, and interactive user interface.

## Live Demo

[Visit CafeTaccino](https://iiamihsan01-hue.github.io/CafeTaccino/)

## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — responsive design and animations
- **JavaScript** — dynamic interactions

## Features

☕ **Modern Design** - Contemporary cafe aesthetic  
📱 **Responsive** - Works perfectly on all devices  
🎨 **Interactive UI** - Smooth animations and transitions  
📋 **Menu Display** - Beautiful product showcase  
✨ **Professional Layout** - Clean, organized structure  

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/iiamihsan01-hue/CafeTaccino.git
   cd CafeTaccino
   ```

2. Open `index.html` in your browser

## Navigation

The website includes:
- Home page with hero section
- Menu/Products section
- About the cafe
- Contact information
- Image gallery

## Customization

To customize for your cafe:
- Edit content in `index.html`
- Update colors and fonts in CSS files
- Replace images in the Media folder with your own cafe photos
- Modify business information and contact details
